# local-study-site

一个给编程 Agent 使用的 skill：把自己合法持有的 PDF、文档、图片和音视频整理成**可双击 `index.html` 打开**的本地学习网站。大批量 OCR 和语音转录使用本机程序与模型；在线大模型可按用户的隐私要求审校少量疑难页。网站采用普通 HTML、CSS、JavaScript，无前端框架和在线资源。

## 使用

将仓库中的 `SKILL.md` 放入你的 Agent 所支持的 skill 目录，然后在资料目录中提出类似请求：

> 使用 local-study-site，把这个目录里的资料整理成我能双击打开的本地学习网站。原件只读，PDF 先提取文字层，必要时用本机 OCR；视频用本机转录。在线大模型只审校疑难页和抽样页面。先做一小份样本，核对后再处理其余资料。

如果本机还没有 OCR 或语音转录模型，skill 会保留原件入口并报告待处理项，不会自行把整批资料交给在线模型。若你要求**全程本地**，编程 Agent 本身也须在本机运行；云端 Agent 即使调用本地 OCR，读取到的内容仍可能离开本机。

本仓库只包含通用说明，不包含任何课程原件、截图、转录结果或网站成品。

## 交付预期

- `site/index.html` 可以从文件管理器双击打开。
- 目录和资源链接均为相对路径，不依赖服务器、CDN 或构建命令。
- 原件始终保留，可从页面回看；OCR／转录不确定处明确标出。
- 笔记等学习状态如启用，应能导出备份。
